> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** l'interface de la fiche v2 — une page HTML/CSS/JS servie par Agent
First et ouverte dans une fenêtre d'application Chrome — avec barre latérale,
vue Discussion (modèle, niveau, réponses mises en forme), vue
Accueil / Historique (statistiques, recherche, suppression) et Paramètres.

**Architecture :** `agent_first/web/` contient `index.html`, `app.css`,
`api.js` (appels à l'API du plan A), `outils.js` (fonctions pures testées avec
`node --test`) et `app.js` (état, affichage, événements). Agent First sert `/`
et `/static/...` sans cache ; `python -m agent_first --ouvrir` ouvre la fenêtre
d'app (`chrome.exe --app=...`) dès que le serveur répond.

**Tech Stack :** HTML, CSS, JavaScript (modules ES, sans dépendance ni outil
de compilation), FastAPI `StaticFiles`, Node 22 (`node:test`) pour les tests
JavaScript, pytest.

**Spec :** `docs/superpowers/specs/2026-10-15-gemini-agent-first-v2-design.md`
(§4.4 l'app web, §4.5 lancement) ; API produite par
`docs/superpowers/plans/2026-10-15-v2a-pilote-historique-api.md`.

## Global Constraints

- Style des maquettes validées : fond `#0d0d0f`, barre `#111114`, cartes `#17171a`, cartes internes `#1e1e22`, bordures `#26262b`, texte `#f4f4f5` / `#a1a1aa` / `#6b6b75`, accent vert `#2fd99b` ; police système Segoe UI ; coins très arrondis ; pastille blanche d'état en bas à droite.
- Aucune ressource chargée depuis Internet (icônes en SVG intégré, polices système).
- Le HTML des réponses Gemini est déjà nettoyé par Agent First (nh3) ; tout autre texte est inséré avec `textContent`, jamais en HTML.
- Préférences de ce navigateur (modèle/niveau par défaut, barre repliée) dans `localStorage`, chaque accès protégé par `try/catch`.
- Agent First : `127.0.0.1:8765` ; fenêtre d'app = Chrome habituel de l'utilisateur (pas de `--user-data-dir`), jamais le Chrome dédié.
- Textes en français. Commits terminés par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` puis `git push` (branche `main`).
- Réglages Gemini de l'utilisateur à remettre après les essais : **4 Argon** + **Min.** (`python -m pilote.modes --modele "4 Argon" --niveau "Min."`).
- Écart assumé avec la fiche §3 : le niveau n'est pas grisé « par modèle » (Gemini propose les 3 niveaux pour les 4 modèles et l'API ne renvoie qu'une liste de niveaux) ; le sélecteur de niveau est masqué si la liste est vide.

## Review Focus

1. **Double envoi** (Entrée tapée deux fois, ou clic pendant l'attente) : un seul message part → garde `etat.occupe` dans `envoyer()` ; vérification tâche 4 étape 2.
2. **Agent First arrêté pendant l'utilisation** : message d'erreur dans le fil, texte remis dans la saisie, pastille « Agent First arrêté » → vérification tâche 4 étape 5.
3. **Titre très long ou sur plusieurs lignes** dans la barre latérale et l'historique : coupé proprement sur une ligne → `titreDepuis` testé (tâche 2) + CSS `text-overflow: ellipsis` ; vérification tâche 3.
4. **Réponse avec tableau large ou long bloc de code** : défilement horizontal dans la carte, la page ne déborde pas → CSS `.markdown pre/table { overflow-x: auto }` ; vérification tâche 4 étape 3.
5. **`localStorage` indisponible** : l'app fonctionne quand même (valeurs par défaut) → `lire()` / `ecrire()` protégés ; relu en tâche 3.

```python
"""Ouvrir l'app dans une fenêtre d'application Chrome (sans onglets ni barre d'adresse).

C'est le Chrome habituel de l'utilisateur qui l'affiche, pas le Chrome dédié à Gemini.
"""
import logging
import subprocess
import time
import urllib.request
from pathlib import Path
from typing import Callable

journal = logging.getLogger(__name__)


def commande_fenetre(chemin_chrome: Path, url: str) -> list[str]:
    return [str(chemin_chrome), f"--app={url}", "--window-size=1280,820"]


def repond(url: str) -> bool:
    try:
        with urllib.request.urlopen(url, timeout=1):
            return True
    except OSError:
        return False


def ouvrir_quand_pret(
    chemin_chrome: Path,
    url: str,
    est_pret: Callable[[], bool],
    lancer: Callable[[list[str]], object] = subprocess.Popen,
    delai: float = 30.0,
    intervalle: float = 0.3,
) -> bool:
    """Attend que le serveur réponde, puis ouvre la fenêtre d'app."""
    fin = time.monotonic() + delai
    while time.monotonic() < fin:
        if est_pret():
            lancer(commande_fenetre(chemin_chrome, url))
            return True
        time.sleep(intervalle)
    journal.warning("Agent First ne répond pas : fenêtre de l'app non ouverte")
    return False
```

```js
// Fonctions pures de l'app (sans DOM), testées avec `node --test tests/web/`.

const LONGUEUR_TITRE = 60;
const MOIS = ["janv.", "févr.", "mars", "avr.", "mai", "juin", "juil.", "août", "sept.", "oct.", "nov.", "déc."];

function debutDuJour(date, decalageJours = 0) {
  const jour = new Date(date);
  jour.setHours(0, 0, 0, 0);
  jour.setDate(jour.getDate() + decalageJours);
  return jour.getTime();
}

export function groupesParDate(conversations, maintenant = new Date()) {
  const groupes = [
    { titre: "Aujourd'hui", depuis: debutDuJour(maintenant) },
    { titre: "Hier", depuis: debutDuJour(maintenant, -1) },
    { titre: "7 derniers jours", depuis: debutDuJour(maintenant, -6) },
    { titre: "Plus ancien", depuis: -Infinity },
  ].map((groupe) => ({ ...groupe, conversations: [] }));
  for (const conversation of conversations) {
    const quand = new Date(conversation.modifie_le).getTime();
    groupes.find((groupe) => quand >= groupe.depuis).conversations.push(conversation);
  }
  return groupes
    .filter((groupe) => groupe.conversations.length)
    .map(({ titre, conversations: liste }) => ({ titre, conversations: liste }));
}

export function formaterDuree(secondes) {
  if (secondes == null) return "";
  const total = Math.round(secondes);
  if (total < 60) return `${total} s`;
  const minutes = Math.floor(total / 60);
  const reste = total % 60;
  return reste ? `${minutes} min ${reste} s` : `${minutes} min`;
}

export function formaterDate(iso, maintenant = new Date()) {
  const date = new Date(iso);
  const heure = `${String(date.getHours()).padStart(2, "0")}:${String(date.getMinutes()).padStart(2, "0")}`;
  const jour = debutDuJour(date);
  if (jour === debutDuJour(maintenant)) return `aujourd'hui ${heure}`;
  if (jour === debutDuJour(maintenant, -1)) return `hier ${heure}`;
  const texte = `${date.getDate()} ${MOIS[date.getMonth()]}`;
  return date.getFullYear() === new Date(maintenant).getFullYear() ? texte : `${texte} ${date.getFullYear()}`;
}

export function titreDepuis(texte) {
  const titre = texte.split(/\s+/).filter(Boolean).join(" ");
  return titre.length <= LONGUEUR_TITRE ? titre : `${titre.slice(0, LONGUEUR_TITRE - 1)}…`;
}

export function metaMessage(message) {
  return [
    "Gemini",
    message.modele,
    message.niveau && `réflexion ${message.niveau}`,
    message.duree != null && formaterDuree(message.duree),
  ]
    .filter(Boolean)
    .join(" · ");
}
```

// Appels à l'API d'Agent First. Lève une Error dont le message s'affiche tel quel.

export async function appeler(methode, chemin, corps) {
  let reponse;
  try {
    reponse = await fetch(chemin, {
      method: methode,
      headers: corps ? { "Content-Type": "application/json" } : {},
      body: corps ? JSON.stringify(corps) : undefined,
    });
  } catch {
    throw new Error("Agent First n'est pas démarré.");
  }
  let contenu = {};
  try {
    contenu = await reponse.json();
  } catch {
    // réponse vide ou illisible : le code HTTP suffit
  }
  if (!reponse.ok) {
    throw new Error(contenu.erreur || `Erreur d'Agent First (code ${reponse.status}).`);
  }
  return contenu;
}

function choisirReglages(modele, niveau) {
  const { modeles, niveaux } = etat.modes;
  const existe = (liste, nom) => liste.some((o) => o.nom === nom);
  const actif = (liste) => liste.find((o) => o.actif)?.nom ?? liste[0]?.nom ?? null;
  etat.modele = existe(modeles, modele) ? modele : actif(modeles);
  etat.niveau = existe(niveaux, niveau) ? niveau : actif(niveaux);
  dessinerReglages();
}

function dessinerReglages() {
  $("nom-modele").textContent = etat.modele ?? "Modèle";
  $("menu-modeles").replaceChildren(
    ...etat.modes.modeles.map((m) => {
      const option = element("button", "option");
      option.type = "button";
      option.setAttribute("role", "option");
      option.setAttribute("aria-selected", String(m.nom === etat.modele));
      option.append(element("span", "option-nom", m.nom), element("span", "option-desc", m.description));
      option.addEventListener("click", () => {
        etat.modele = m.nom;
        fermerMenu();
        dessinerReglages();
      });
      return option;
    }),
  );
  $("niveaux").hidden = !etat.modes.niveaux.length;
  $("niveaux").replaceChildren(
    ...etat.modes.niveaux.map((n) => {
      const bouton = element("button", n.nom === etat.niveau ? "actif" : "", n.nom);
      bouton.type = "button";
      bouton.title = n.description;
      bouton.setAttribute("role", "radio");
      bouton.setAttribute("aria-checked", String(n.nom === etat.niveau));
      bouton.addEventListener("click", () => {
        etat.niveau = n.nom;
        dessinerReglages();
      });
      return bouton;
    }),
  );
}

async function chargerConversations() {
  const recherche = $("recherche").value.trim();
  const liste = $("liste-conversations");
  let conversations;
  try {
    conversations = await appeler("GET", `/api/conversations?${new URLSearchParams({ recherche })}`);

    liste.replaceChildren(element("p", "vide", recherche ? "Aucun résultat." : "Tes conversations apparaîtront ici."));
    return;
  }
  const contenu = [];
  for (const groupe of groupesParDate(conversations)) {

// ---------- discussion ----------

function bulle(message) {
  if (message.role === "toi") {
    const b = element("div", "bulle toi");
    b.append(element("div", "texte-toi", message.texte));
    return b;
  }
  if (message.role === "erreur") {
    const b = element("div", "bulle erreur");
    const meta = element("div", "meta");
    meta.append(element("span", "point"), document.createTextNode("Erreur"));
    b.append(meta, element("div", null, message.texte));
    return b;
  }
  const carte = element("article", "bulle gemini");
  const meta = element("div", "meta");
  meta.append(element("span", "point"), document.createTextNode(metaMessage(message)));
  const contenu = element("div", "markdown");
  if (message.html) {
    contenu.innerHTML = message.html; // déjà nettoyé par Agent First (nh3)
  } else {
    contenu.textContent = message.texte;
  }
  const copier = element("button", "icone");
  copier.type = "button";
  copier.title = "Copier la réponse";
  copier.setAttribute("aria-label", "Copier la réponse");
  copier.append(icone("i-copier"));
  copier.addEventListener("click", async () => {
    try {
      await navigator.clipboard.writeText(message.texte);
      signaler("Réponse copiée", VERT);
    } catch {
      signaler("Copie impossible", ROUGE);
    }
  });
  const actions = element("div", "actions");
  actions.append(copier);
  carte.append(meta, contenu, actions);
  return carte;
}

  titre.append(element("span", "accent", "Gemini"));

  return bloc;
}

async function ouvrirConversation(identifiant) {
  try {
    const { conversation, messages } = await appeler("GET", `/api/conversations/${identifiant}`);
    etat.courante = conversation.id;
    $("titre-conversation").textContent = conversation.titre || "Conversation";

    $("fil").replaceChildren(...messages.map(bulle));
    afficherVue("discussion");
    defilerEnBas();
    chargerConversations();

    signaler(e.message, ROUGE);

async function envoyer() {
  const texte = $("saisie").value.trim();
  if (!texte || etat.occupe) return;
  etat.occupe = true;
  $("form-saisie").classList.add("occupe");
  $("saisie").value = "";
  ajusterSaisie();

  const fil = $("fil");
  fil.querySelector(".vide-discussion")?.remove();
  fil.append(bulle({ role: "toi", texte }));
  const attente = element("div", "bulle attente");
  const libelle = element("span", null, "Gemini réfléchit…");
  attente.append(element("span", "points"), libelle);
  fil.append(attente);
  defilerEnBas();
  if (!etat.courante) $("titre-conversation").textContent = titreDepuis(texte);

  const debut = Date.now();
  signaler("Gemini réfléchit…", ORANGE);
  const minuteur = setInterval(() => {
    const ecoule = `Gemini réfléchit… ${formaterDuree((Date.now() - debut) / 1000)}`;
    libelle.textContent = ecoule;
    signaler(ecoule, ORANGE);
  }, 1000);

  try {
    if (!etat.courante) {
      const conversation = await appeler("POST", "/api/conversations", { modele: etat.modele, niveau: etat.niveau });
      etat.courante = conversation.id;
    }
    const { message } = await appeler("POST", `/api/conversations/${etat.courante}/messages`, {
      texte,
      modele: etat.modele,
      niveau: etat.niveau,
    });
    attente.replaceWith(bulle(message));
    signaler("Gemini prêt", VERT);
  } catch (e) {
    attente.replaceWith(bulle({ role: "erreur", texte: e.message }));
    $("saisie").value = texte; // pour pouvoir le renvoyer
    ajusterSaisie();
    signaler(e.message === "Agent First n'est pas démarré." ? "Agent First arrêté" : "Erreur", ROUGE);
    if (/n'est pas proposé/.test(e.message)) chargerModes();
  } finally {
    clearInterval(minuteur);
    etat.occupe = false;
    $("form-saisie").classList.remove("occupe");
    defilerEnBas();
    chargerConversations();
  }
}

async function chargerAccueil() {

function dessinerCartes(s) {
  const cartes = [
    ["Conversations", "Sur la période", "i-messages", String(s.conversations)],
    ["Messages", "Envoyés à Gemini", "i-graphique", String(s.messages)],

      rond.append(icone(nomIcone));

      return carte;
    }),
  );
}

function dessinerLignes(conversations, recherche) {
  const lignes = $("lignes-historique");
  if (!conversations.length) {
    lignes.replaceChildren(
      element("p", "vide", recherche ? "Aucune conversation ne correspond." : "Aucune conversation sur cette période."),
    );
    return;
  }
  lignes.replaceChildren(
    ...conversations.map((c) => {
      const ligne = element("div", "ligne");
      const ouvrir = element("button", "ligne-titre", c.titre || "Sans titre");
      ouvrir.type = "button";
      ouvrir.title = c.titre;
      ouvrir.addEventListener("click", () => ouvrirConversation(c.id));
      const nombre = `${c.nb_messages} message${c.nb_messages > 1 ? "s" : ""}`;
      const infos = element("span", "ligne-infos", [c.modele, nombre, formaterDate(c.modifie_le)].filter(Boolean).join(" · "));
      const supprimer = element("button", "icone");
      supprimer.type = "button";
      supprimer.title = "Retirer de l'historique";
      supprimer.setAttribute("aria-label", `Retirer « ${c.titre} » de l'historique`);
      supprimer.append(icone("i-corbeille"));
      supprimer.addEventListener("click", () => supprimerConversation(c));
      ligne.append(ouvrir, infos, supprimer);
      return ligne;
    }),
  );
}

async function supprimerConversation(c) {
  if (!confirm(`Retirer « ${c.titre} » de l'historique de l'app ?\nLa conversation reste dans Gemini.`)) return;
  try {
    await appeler("DELETE", `/api/conversations/${c.id}`);
    if (etat.courante === c.id) etat.courante = null;
    chargerAccueil();
    chargerConversations();
  } catch (e) {
    signaler(e.message, ROUGE);
  }
}
